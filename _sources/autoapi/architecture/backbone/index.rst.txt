.. py:function:: ConvBackbone(n_outputs: int, H: int, W: int, in_channels: int, base_filter: int, channel_schedule: list) -> torch.nn.Sequential

   Baseline CNN: strided conv blocks → linear classification head.

   :param n_outputs: Number of output logits.
   :param H: Input image height — must be divisible by stride^len(channel_schedule).
   :param W: Input image width  — must be divisible by stride^len(channel_schedule).
   :param in_channels: Input image channels.
   :param base_filter: Base filter count, scaled per block by channel_schedule.
   :param channel_schedule: Filter multipliers per block — controls depth and width.

   :returns: nn.Sequential backbone.

   :raises ValueError: If H or W are not divisible by stride^len(channel_schedule).
