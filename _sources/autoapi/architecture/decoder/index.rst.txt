.. py:function:: Decoder(latent_dim: int, base_filter: int) -> torch.nn.Sequential

   :param base_filter: Base filter count — must match encoder.

   :returns: nn.Sequential decoder.

   :raises AssertionError: If channel, kernel, padding schedules differ in length.
